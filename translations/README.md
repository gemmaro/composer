# Composerの日本語訳

このディレクトリではComposerのガイド等を日本語訳を管理します。

翻訳管理にはpo4aを使用します。
このツールはほとんどのパッケージ管理ツールでインストールできるはずです。

原文が更新されたとき、日本語訳を更新するには、おおよそ以下の工程をします。

1. `git fetch`により本家のリモートから最新のコミットを取得
2. `git merge`により本家の`main`ブランチから`ja`ブランチにマージ
3. リポジトリのルートから`make -C translations`とします。
   * 効果：POファイルが更新されるはずです。
   * お勧め：この時点でコミットを作っておくとよいでしょう。
4. POファイルを編集して翻訳を更新します。
5. リポジトリのルートから`make -C translations`とします。
   * 効果：翻訳のMarkdownファイルが更新されるはずです。
6. コミットを作成・整頓
7. `git push`でこの日本語訳のリポジトリにコミットを送信
